# Changelog

## 1.1.0 — 2026-11-19
- New themes: **CAAL Institucional** (paper, forest green, Marcellus + Poppins) and **CAAL Hands On** (black, neon green glow, Archivo), based on the CAAL design system.
- Fixed: bottom edge of the top toolbar was clipped.
- Fixed: empty gap between the deck list header and the first deck.
- Fixed: deck table was wider than the summary cards above it; long deck names now wrap.
- Fixed: group box titles overlapping their frame in Preferences and other dialogs.
- Fixed: toolbar items showed a grey button background in some themes.
- Fixed: Edit / More buttons touching the window edge in the reviewer.
- Fixed: Old Money fonts were large enough to clip text in fixed-width buttons and tabs.
- Light themes now blend Anki's default white card background into the theme (option `harmonizar_cartao`).

## 1.0.0 — 2026-10-17
- First public release.
- Four themes: Modern Dark, Modern Light, Old Money, Old Money Night.
- Live theme switching from Tools → Themes.
- Restyles deck list, overview, reviewer bar, browser, editor, statistics, deck options, Preferences and all dialogs.
- Bundled fonts: Inter, Cormorant Garamond, Crimson Pro.
- English and Portuguese interface text.
