**tema / theme** — `"moderno_escuro"` (Modern Dark), `"moderno_claro"` (Modern Light), `"old_money"`, `"old_money_noite"` (Old Money Night), `"caal"` (CAAL Institucional), `"caal_handson"` (CAAL Hands On). Easiest: **Tools → Themes** / **Ferramentas → Temas**.

**cor_destaque / accent color** — `""` uses each theme's own color. Any hex (e.g. `"#3b82f6"`) forces that accent in every theme.

**mostrar_saudacao / show greeting** — greeting and today's summary above the deck list.

**harmonizar_cartao / blend card background** — light themes: replaces the default white card background with the theme paper color. Cards with a custom background are left alone.

**barra_de_titulo_colorida / colored title bar** — Windows 11 only: paints window title bars with the theme color.
