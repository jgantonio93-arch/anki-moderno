Anki Moderno restyles the entire Anki interface with four hand-tuned themes — not just the deck list, but the reviewer, browser, card editor, statistics, deck options, menus and every pop-up dialog. Themes • Modern Dark — deep graphite with a violet accent. • Modern Light — clean, airy and bright. • Old Money — ivory paper, British racing green and gold rules, with classic serif typography (Cormorant Garamond + Crimson Pro). • Old Money Night — dark green leather with brass details. How to use Go to Tools → Themes and pick a theme. It applies immediately, no restart needed. Each theme also switches Anki's light/dark mode to match. If you change light/dark in Preferences, the add-on switches to the matching pair (Modern Dark ↔ Modern Light, Old Money ↔ Old Money Night). What changes • Deck list with a daily greeting and a summary of New / Learning / Review cards. • Restyled top toolbar, deck overview and "Study Now" button. • Colored answer buttons (Again / Hard / Good / Easy) and a highlighted "Show Answer". • Browser, Add/Edit editor, statistics, deck options, card info and Preferences. • Native menus, buttons, inputs, tables, tabs, scrollbars and tooltips. • Bundled fonts (Inter, Cormorant Garamond, Crimson Pro), so it looks the same on every computer. • Windows 11: window title bars take the theme color. Your cards are left alone The add-on does not touch your note types. Fonts, colors and layouts defined in your card templates are preserved. Tip: a card style with background: transparent and color: var(--fg) blends perfectly with every theme. Options (Tools → Add-ons → Anki Moderno → Config) • tema — active theme (easier: Tools → Themes). • cor_destaque — leave empty to use each theme's accent, or set any hex color (e.g. "#3b82f6"). • mostrar_saudacao — show/hide the greeting above the deck list. • barra_de_titulo_colorida — Windows 11 colored title bars. Compatibility Tested on Anki 24.06, 25.02 and 26.9. Uses only Anki's own cross-platform APIs, so it runs on Windows, macOS and Linux. Interface text follows Anki's language (English or Portuguese). Dialogs that are already open when you switch themes update the next time they are opened. Support & source code Bugs and suggestions: GitHub issues.
